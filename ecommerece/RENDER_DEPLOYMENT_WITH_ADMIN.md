# Render Deployment Guide with Admin User Setup

## 🚀 Automatic Admin User Creation on Deployment

This guide shows how to deploy your Django e-commerce application to Render with automatic admin user creation.

## 📋 Prerequisites

1. Render account
2. GitHub repository with your code
3. PostgreSQL database (Render provides this)

## 🔧 Deployment Steps

### 1. Environment Variables Setup

In your Render dashboard, add these environment variables:

```
DJANGO_SETTINGS_MODULE=ecommerece.settings
SECRET_KEY=<auto-generated>
DEBUG=False
ALLOWED_HOSTS=your-app-name.onrender.com
RENDER=True
ADMIN_PASSWORD=<auto-generated or custom>
DATABASE_URL=<auto-generated from database>
```

### 2. Build Command

The build command in `render.yaml` will automatically:
- Install dependencies
- Run migrations
- Create admin superuser
- Collect static files

```bash
pip install -r requirements.txt && python manage.py collectstatic --noinput && python manage.py migrate && python manage.py create_admin_user --username root --email admin@example.com
```

### 3. Manual Commands (if needed)

If you need to run commands manually on Render:

#### Create Admin User
```bash
python manage.py create_admin_user --username root --email admin@example.com
```

#### With Custom Password
```bash
python manage.py create_admin_user --username root --password your_secure_password --email admin@example.com
```

#### Run Migrations Only
```bash
python manage.py migrate
```

## 🔑 Admin Access

After deployment, you can access the admin panel at:
- **URL**: `https://your-app-name.onrender.com/admin/`
- **Username**: `root`
- **Password**: Check your `ADMIN_PASSWORD` environment variable in Render dashboard
- **Email**: `admin@example.com`

## 🛠️ Management Commands Available

### Create Admin User
```bash
python manage.py create_admin_user [options]
```

Options:
- `--username`: Username (default: root)
- `--password`: Password (default: from ADMIN_PASSWORD env var or root123)
- `--email`: Email (default: admin@example.com)

### Examples
```bash
# Create with default settings
python manage.py create_admin_user

# Create with custom username and email
python manage.py create_admin_user --username admin --email admin@yourdomain.com

# Create with custom password
python manage.py create_admin_user --username admin --password MySecurePassword123
```

## 🔒 Security Notes

1. **Change Default Password**: Always set a strong `ADMIN_PASSWORD` environment variable
2. **Secure Environment Variables**: Never commit passwords to your repository
3. **HTTPS Only**: Render provides HTTPS by default
4. **Database Security**: Use Render's managed PostgreSQL database

## 🐛 Troubleshooting

### Admin User Not Created
1. Check if user already exists
2. Verify environment variables are set
3. Check build logs in Render dashboard

### Database Connection Issues
1. Verify `DATABASE_URL` is correctly set
2. Check if migrations ran successfully
3. Ensure database is accessible

### Permission Issues
1. Verify user has `is_staff=True` and `is_superuser=True`
2. Check user role is set to 'admin'
3. Ensure user is active (`is_active=True`)

## 📝 Environment Variables Reference

| Variable | Description | Required | Default |
|----------|-------------|----------|---------|
| `SECRET_KEY` | Django secret key | Yes | Auto-generated |
| `DEBUG` | Debug mode | Yes | False |
| `ALLOWED_HOSTS` | Allowed hosts | Yes | your-app.onrender.com |
| `DATABASE_URL` | Database connection | Yes | Auto-generated |
| `ADMIN_PASSWORD` | Admin user password | No | root123 |
| `RENDER` | Render environment flag | Yes | True |
